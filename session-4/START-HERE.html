Session 4 — בונים סוכן RAG

שלושה תרגילים מתחברים: מסמכים → Index → חיפוש → תשובה עם מקורות. פתחו את התיקייה כולה ב־VS Code ושמרו את שלוש תיקיות התרגילים זו לצד זו.

מה נדרש מראש?

  • Python 3.10 ומעלה ו־VS Code. אפשר להיעזר ב־Claude Code לכתיבת הקוד ולהבנתו.
  • ה־embeddings מחושבים מקומית ב־Ollama עם EmbeddingGemma. ליצירת התשובה בחרו מודל טקסט מקומי ב־Ollama, או Claude דרך Anthropic API עם מפתח אישי וגישה פעילה. Claude Code אינו ספק embeddings.
  • הסברים, פקודות לכל מערכת הפעלה ותקלות נפוצות נמצאים במדריך של כל תרגיל. אין להכניס מפתחות לקוד או לשתף אותם.

סדר העבודה

  1. תרגיל 1 — Indexing: קוראים את המסמכים, בונים Chunking ופרטי מקור, מחשבים embeddings ושומרים אינדקס מקומי.
  2. תרגיל 2 — Retrieval: משתמשים באינדקס הראשון, בונים Cosine Similarity ו־Top-k ומייצאים תוצאות חיפוש.
  3. תרגיל 3 — Generation: בונים את ההקשר, שולחים למודל ומציגים תשובה מול המקורות.

בכל תרגיל שתי משימות בונוס למתקדמים. התחילו בליבה. הודעת TODO בתחילת הדרך צפויה: זה החלק שעליכם לבנות.

איך התוצרים מתחברים?

תרגיל 2 קורא את exercise-1-indexing/build/index.json. תרגיל 3 קורא את exercise-2-retrieval/build/search-results.json. שמרו על שמות התיקיות; המדריכים מסבירים גם איך למסור נתיב מפורש.

מה כלול?

מצגת השיעור, מסמכי התרחיש, קוד התחלתי עם הערות בעברית, בדיקות והוראות. פתרונות המרצה ומדריכי ההוראה אינם בחבילה.

מה נבדק?

הקבצים והעברת הנתונים בין התרגילים נבדקו ללא רשת ועם תגובות API מדומות. מסלול offline_fixture בודק את התשתית בלבד: הוא אינו מפעיל מודל ואינו מוכיח איכות חיפוש או תשובה. מסלולי הענן והמקומי עדיין דורשים בדיקה חיה; יש לפעול לפי הנחיות המרצה.
