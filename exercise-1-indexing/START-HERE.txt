Exercise 1: Indexing

1. Open README-HE.html in your browser.
2. Open this entire folder in VS Code.
3. Build the two TODO functions in chunking.py.
4. Prepare chunks, inspect them, then create real embeddings.

Embeddings are computed locally with Ollama (embeddinggemma).
Claude Code helps you write/run code. It is not the embeddings provider.

The offline fixture route checks files only; its vectors are not semantic.
