מוסיפים ל־Jarvis כלי שעובד עם יישום

בתרגיל הקודם Jarvis ענה מתוך הפתקים שלכם. עכשיו תוסיפו לו גישה ליישום: למשל לקרוא משימות מלוח או למלא טופס בדפדפן. בחרו חיבור אחד, הגדירו פעולה אחת שתרצו לבצע ובדקו את התוצאה בתוך היישום.

בסיום: תציגו בקשה ל־Jarvis, את הכלי שהופעל ואת התוצאה שראיתם ביישום. חיבור MCP שכבר קיים מספק את הכלים; Claude Code מסייע להוסיף את החיבור לקוד של Jarvis.

לפני שמתחילים

  • פתחו את פרויקט Jarvis שבו עבדתם ואת Claude Code מתוך הפרויקט.
  • הפעילו את היישום שבחרתם לפי כרטיס ההכנה המתאים למטה.
  • הכינו פתק סינתטי אחד או בקשה קצרה שאיתה תבדקו את החיבור.
  • ודאו שיש בפרויקט דרך לגלות ולהפעיל כלי MCP. אם ההתאמה עדיין בעבודה, התחילו בבדיקת המחבר מתוך Claude Code והשלימו את החיבור ל־Jarvis בעזרתו.

מה עושים במהלך 40 הדקות?

  1. 0–6 דקות — בוחרים בקשה. כתבו משפט אחד ש־Jarvis צריך לבצע. לדוגמה: ״הצג את המשימות בפרויקט שלי״ או ״מלא בטופס בקשת בדיקה מתוך הפתק הזה״.
  2. 6–16 דקות — מחברים את הכלי. פעלו לפי כרטיס ההכנה. בקשו מ־Claude Code להראות את הכלים שהחיבור מספק, ואז להתאים את Jarvis להפעלת כלי אחד שנחוץ לבקשה.
  3. 16–28 דקות — מפעילים דרך Jarvis. שלחו את הבקשה ובדקו איזה כלי נבחר ואיזה קלט נשלח אליו. במסלול טופס, הציגו את הפרטים לאישור לפני שמירה.
  4. 28–36 דקות — משווים ליישום. פתחו את הלוח או את הטופס ובדקו שהנתונים תואמים לבקשה ולמקור.
  5. 36–40 דקות — מסבירים לחבר צוות. הראו את הבקשה, את קריאת הכלי ואת התוצאה. ציינו מה כבר עובד ומה דורש השלמה.

בקשה שאפשר לתת ל־Claude Code: ״בדוק איך Jarvis בפרויקט הזה מפעיל כלים. חבר אליו את שרת ה־MCP שבחרתי, הצג את הכלים שלו והפעל את הפעולה שביקשתי. שמור על הנתונים וההרשאות שהגדרתי, והראה לי את בקשת הכלי ואת התוצאה שחזרה.״

  • אחרי אישורכם הופיעה בטופס רשומה שמורה עם מקור.

בדיקה מתוך Claude Code מאשרת שהמחבר עובד עם אותו לקוח. הפעלה מתוך Jarvis היא הבדיקה שהחיבור נוסף לעוזר שלכם. רשמו בבירור איזו משתי הבדיקות השלמתם.
