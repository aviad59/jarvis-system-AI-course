המשך לבחירה בתרגיל 2

איך מודל מפעיל תוכנה דרך שורת פקודה?

CLI הוא ממשק של פקודות טקסט. בדוגמה הזו המודל מבקש יצירת מסמך, וקוד Python מפעיל פקודות של LibreOffice. התוצר הוא קובץ ODT ו־PDF שאפשר לפתוח ולבדוק.

מי עושה מה?

  1. Ollama מפעיל מודל מקומי שמקבל בקשה ותיאור של כלי.
  2. ollama_cli.py הוא קוד הדוגמה שהוכן לתרגיל. הוא קורא את בחירת המודל ומפעיל פקודות מוגדרות.
  3. ממשק הפקודות של LibreOffice מספק פעולות ליצירת מסמך ולהוספת טקסט.
  4. LibreOffice המקומי מפיק את המסמך ואת ה־PDF.

בדוגמה שם הכלי הוא create_connection_document. זהו שם של פונקציה בקוד התרגיל, שפירושה ״צור מסמך לבדיקת החיבור״.

הקבצים ומה עושים איתם

הכנה לפני השיעור

  • Ollama והמודל qwen3:8b מוכנים להפעלה.
  • LibreOffice, Python ו־Git מותקנים.
  • פתחו מסוף בתיקייה exercise-2-mcp, תיקיית האב של cli.
  • התקינו את ממשק הפקודות מהגרסה המקובעת שבפקודה.
# יוצרים סביבת Python לדוגמה ב־Windows
py -3 -m venv .venv-cli
# מתקינים ממשק פקודות שנבחר ממאגר CLI-Anything
.\.venv-cli\Scripts\python.exe -m pip install "git+https://github.com/HKUDS/CLI-Anything.git@34f519533bc175d2fe287ab8316b0dd99bb9cc43#subdirectory=libreoffice/agent-harness"
# בודקים שממשק הפקודות זמין
.\.venv-cli\Scripts\cli-anything-libreoffice.exe --help

ב־macOS/Linux יוצרים סביבה עם python3 ומשתמשים בנתיבים .venv-cli/bin/python ו־.venv-cli/bin/cli-anything-libreoffice.

שלב 1: בודקים את הפקודות עם קלט ידוע

# מריצים את יצירת המסמך ומקבלים קובצי תוצאה
.\.venv-cli\Scripts\python.exe cli/ollama_cli.py --mode direct --cli .\.venv-cli\Scripts\cli-anything-libreoffice.exe --output cli/build/direct-trace.json

פתחו את נתיבי המסמכים שהופיעו ברישום. הכותרת היא Cedar connection check, והפסקה היא משפט בדיקה באנגלית שמציין שזהו מסמך לבדיקת חיבור מקומי. אלו נתוני בדיקה קבועים של הדוגמה.

שלב 2: נותנים למודל לבחור את הכלי

# המודל המקומי בוחר את הכלי והקוד מפעיל את פקודות היישום
.\.venv-cli\Scripts\python.exe cli/ollama_cli.py --mode ollama --model qwen3:8b --cli .\.venv-cli\Scripts\cli-anything-libreoffice.exe --output cli/build/ollama-trace.json
  • ברישום ההרצה פתחו את בקשת הכלי ואת הקלט שבחר המודל.
  • פתחו את ה־PDF שנוצר והשוו את תוכנו לבקשה.
  • השוו בין המסלול הישיר למסלול שבו המודל בחר את הכלי.
דוגמת Ollama–CLI נבדקה בפועל ב־macOS והפיקה קובצי ODT ו־PDF עם התוכן שהתבקש. פקודות Windows צריכות חזרה במחשבי הכיתה. שילוב הקוד בתוך Jarvis הוא שלב התאמה נפרד בפרויקט שלכם.
