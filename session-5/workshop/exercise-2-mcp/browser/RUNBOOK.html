ממלאים טופס מקומי דרך Playwright MCP

Playwright MCP נותן לעוזר כלים לקריאת עמוד, מילוי שדות ולחיצה. כאן תשתמשו בטופס תרגול מוכן במחשב שלכם.

הקבצים

  • RUNBOOK.html — כרטיס ההכנה וההפעלה שאתם קוראים עכשיו.
  • local-form.html — יישום התרגול: טופס בקשת בדיקה, תצוגה מקדימה ורשומות שנשמרות בדפדפן.

לפני התרגיל

  • הכינו Node 18 ומעלה, Python ודפדפן Edge ב־Windows.
  • פתחו PowerShell בתיקיית exercise-2-mcp.
  • הפעילו את תצוגת הטופס בפקודה הבאה והשאירו את החלון פועל.
# מציגים את תיקיית הטופס במחשב המקומי בלבד
py -3 -m http.server 8768 --bind 127.0.0.1 --directory browser

פתחו http://127.0.0.1:8768/local-form.html. במסלול macOS משתמשים ב־python3 במקום py -3.

זהו תהליך תצוגה מקומי במחשב שלכם. החלון נשאר פעיל בזמן העבודה.

מחברים את כלי הדפדפן

פתחו חלון נוסף בפרויקט Jarvis שבו פועל Claude Code. פקודת ההכנה הבאה ל־Windows מוסיפה את המחבר. הורדת החבילה מתבצעת לפני זמן התרגיל.

# מוסיפים ללקוח את שרת כלי הדפדפן
claude mcp add --transport stdio --scope project browser-tools -- cmd /c npx -y @playwright/mcp@0.0.85 --browser msedge --isolated

ב־macOS, עם Chrome מוכן, פקודת ההוספה היא:

# מוסיפים את מחבר הדפדפן בסביבת macOS
claude mcp add --transport stdio --scope project browser-tools -- npx -y @playwright/mcp@0.0.85 --browser chrome --isolated

ב־Claude Code פתחו /mcp ובדקו שהמחבר מופיע ומחובר. בקשו לקרוא את העמוד המקומי ולהציג את השדות שלו. אם Jarvis הוא הלקוח שלכם, הגדירו בו את אותו תהליך MCP באמצעות מתאם הכלים של הפרויקט. חיבור מוצלח ב־Claude Code מאשר את המחבר; בקשה שעובדת מתוך Jarvis מאשרת את שילובו בעוזר.

הפעולה שתבצעו

  1. בחרו פתק שלכם עם פעולת המשך ברורה.
  2. בקשו מהעוזר לפתוח את הכתובת המקומית ולקרוא את שדות הטופס.
  3. בקשו למלא את הפרטים שנמצאים בפתק ולהציג תצוגה מקדימה.
  4. השוו לפרטי המקור ואשרו שמירה.
  5. פתחו את הרשומה שנוספה ובדקו את הפרטים ואת מקור הפתק.

הכלים המרכזיים הם browser_navigate, browser_snapshot, browser_fill_form ו־browser_click. המחבר מפרסם את שדות הקלט המדויקים בקטלוג שלו. העוזר משתמש בזיהוי השדות שהתקבל מקריאת העמוד.

מה נבדק?

  • חבילת Playwright MCP 0.0.85 אומתה ונבדקה ב־macOS עם Chrome.
  • חיבור stdio אמיתי גילה כלים, פתח את העמוד המקומי וקרא את מבנהו.
  • הטופס נבדק בנפרד: תצוגה מקדימה, שמירה, קריאה חוזרת ורענון.
  • הפעלה מתוך Jarvis ובמחשבי Windows צריכה חזרה לפי סביבת הכיתה.

הרשומות נשמרות בפרופיל הדפדפן המקומי. פרופיל isolated הוא פרופיל תרגול נפרד; פתיחת פרופיל חדש מתחילה סשן תרגול חדש.
