בדיקת מוכנות לפני מפגש 5

מכינים לכולם

  • חלצו את כל החבילה לתיקיית עבודה אחת.
  • הפעילו את Jarvis מהשבוע הקודם ושאלו שאלה מהמסמכים שכבר חיברתם.
  • פתחו את פרויקט Jarvis ב־Claude Code.
  • ודאו ש־Ollama והמודל המקומי שבהם עבדתם מוכנים להפעלה.
  • הכינו Obsidian, Python ו־Node לפי מדריכי התרגילים.
  • הכינו את חיבור MCP בפרויקט Jarvis או תכננו עם המרצה את שלב ההתאמה. בדיקת המחבר מתוך Claude Code משמשת בדיקת ביניים.

תרגיל 1

  • פתחו את דף הדרישות.
  • הכינו שתי תיקיות מזוהות: Vault של הפתקים ופרויקט Jarvis של הקוד.
  • בדקו את חיבור הקבצים ואת היכולת להפעיל את הפרויקט הקיים.

תרגיל 2 — בוחרים מסלול

  • Vikunja: הכינו Docker Desktop, הפעילו את הלוח וצרו פרויקט ומשימת בדיקה.
  • דפדפן: הכינו את מחבר Playwright ופתחו את הטופס המקומי.
  • בונוס CLI: ההתקנות מופיעות בכרטיס נפרד למי שבוחר בדוגמה.

תרגיל 3

  • פתחו את דף FastMCP והכינו סביבה נפרדת לפי ההוראות.
  • הריצו verify_example.py ובדקו שמתקבל PASS.
  • בחרו מראש מקור קטן שנגיש לפרויקט: קלט, קובץ, פונקציה או API מוכן.

מצב הבדיקות

  • דוגמת FastMCP והלקוח המצורף נבדקו דרך stdio בפועל.
  • כלי הדפדפן והטופס נבדקו ב־macOS.
  • דוגמת Ollama–CLI הפיקה מסמכים שנבדקו מול הבקשה.
  • מדריך Docker מבוסס על התיעוד הרשמי ותצורת YAML שנבדקה; הרצת הקונטיינר ומסלולי Windows דורשים חזרה בסביבה שלכם.
